# Remaining launch dependencies

The code is a complete service implementation with a locally exercised database-backed preview. It is not an already operating paid production business.

1. **Persistent .NET/container hosting and public staging origin.** Supply an approved host, DNS/TLS and durable API file/key volume, or implement the chosen host's shared storage/backplane before changing the supplied single-instance deployment. The connected Golfers Vercel frontend has no configured .NET runtime/storage. Existing production was preserved.
2. **Payment provider configuration and sandbox acceptance.** Stripe platform/Connect keys, approved merchant account, webhook secrets/API version, final price IDs, live/test mode, country/currency eligibility, tax settings and sandbox end-to-end checkout/refund/subscription checks. No real charge, merchant approval, refund or successful integration has been invented.
3. **Email and real-device push.** Verified sending domain/address and email API key, VAPID keys/support contact, provider monitoring, and actual delivery/browser/device acceptance. Development inbox records are local sink records, not sent mail.
4. **Operational ownership.** Set up runtime/migration database roles, encrypted off-host backups, tested restore target, logs/alerts, support coverage, incident response, retention/export/deletion handling and measured recovery objectives. Container rollout and encrypted restore drill remain host acceptance tasks.
5. **Business/legal publication.** Confirm the operating entity/contact details, final brand/domain/prices, service terms, privacy/data-processing arrangements, safeguarding/guardian processes and regional sales/tax/cancellation requirements. The product does not claim universal regulatory or payment coverage.
6. **Optional AI.** Provide an approved API key/model and evaluate drafts if enabling this optional feature; manual publishing works independently.

Native mobile applications, external federation/scoring/handicap/tee-time integrations and additional interface languages remain explicitly subsequent phases. Club signup, sports selection, currency and time zone configuration are not restricted to UK golf clubs.

No GitHub Actions build, test, review, deployment or rerun was invoked. No automatic Actions workflows were created. Repository workflow safety was rechecked before publishing this release candidate; repeat the check before future pushes/PRs.
